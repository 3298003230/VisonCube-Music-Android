# VisonCube Music for Android

VisonCube Music 是面向 Android 的音乐播放与管理客户端，提供搜索、播放、歌词、歌单、本地音乐、账号与多端同步等功能。

## 下载与更新

请从 [VisonCube Music Android Releases](https://github.com/3298003230/VisonCube-Music-Android/releases) 获取对应设备架构的 APK 与更新说明。应用内更新只使用 VisonCube Music 的发布信息。

## Windows 客户端

Windows 客户端位于 [VisonCube Music Windows](https://github.com/3298003230/VisonCube-Music-Windows)。

## 常用功能

- 管理本地歌单、历史与收藏；
- 使用自定义音源和托管音源；
- 登录账号后同步历史、歌单和配置；
- 支持歌词、主题、横竖屏界面和后台播放；
- 可清理失效歌曲 URL 缓存并更新音源。
